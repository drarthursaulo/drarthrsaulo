## 🚀 Projects

### SporoScan

Digital One Health platform focused on sporotrichosis, connecting health information, people, professionals and services.

🌐 **Current production platform:** https://sporoscan.com.br

The project originally started as **SporoScan SC**, a functional application developed in **Python and Streamlit** with an initial focus on the state of Santa Catarina, Brazil.

It later evolved into **SporoScan**, a national web platform with an expanded scope, redesigned user experience and additional web features, currently deployed using **Cloudflare infrastructure**.

My work on SporoScan includes:

- Product development and iteration
- Web deployment
- Responsive interface development
- Geolocation-based features
- Information architecture
- User experience improvements
- Health information organization
- Continuous testing and improvement

The project represents my interest in combining healthcare knowledge with software and web technologies to build useful digital products.

> The current production source code is private.
